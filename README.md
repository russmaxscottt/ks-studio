# K’s Studio Ultra PWA

iPhone, iPad Pro ve desktop browser için touch + keyboard/mouse destekli DAW prototipi.

## Eklenen Ultra özellikler
- Channel bazlı piano roll: Kick, Snare, Hat, Clap/Perc, 808, Bass, Melody, Piano, Synth
- Mouse tıklama/sürükleme ve dokunmatik hücre boyama
- Klavye kısayolları
- Scale Lock
- Chord Generator
- Channel Rack
- Playlist / Arrangement
- Mixer + FX slot görünümü
- Sample Browser + sample upload
- Synth Library presetleri
- 808 Editor
- Vocal Chain presetleri
- AutoTune sim UI
- Project save/load localStorage
- Export: WAV demo, MIDI-like JSON, stems JSON
- 10 tema
- iPhone + iPad Pro + desktop responsive layout
- K’s Studio ⭐ ikon

## Kurulum
1. Zip'i aç.
2. Tüm dosyaları GitHub repo'ya yükle.
3. Settings > Pages > Deploy from branch > main/root.
4. Safari ile Pages linkini aç.
5. Paylaş > Ana Ekrana Ekle.

## Önemli teknik sınırlar
Bu PWA prototipidir. Gerçek App Store uygulaması, VST/AU host, profesyonel MP3 export, düşük gecikmeli audio engine ve tam DAW performansı için native iOS uygulama gerekir.
